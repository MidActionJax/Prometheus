GIT / GITHUB COMMANDS — Elastic Gas Thermalization demo
==========================================================

Run these from E:\Linkedin in PowerShell or Git Bash:

    git checkout -b demo/elastic-gas-thermalization
    git add .
    git commit -m "Add Elastic Gas Thermalization demo"
    git push -u origin demo/elastic-gas-thermalization

WHAT HAPPENS NEXT
------------------
1. Pushing that branch will make GitHub show a "Compare & pull request"
   button on the repo page (or in the terminal output as a clickable link).
2. Click it. For the PR title, paste:
       Add Elastic Gas Thermalization demo
3. For the PR description box, paste the full contents of
   PR_DESCRIPTION.md (in this same folder).
4. Click "Create pull request".
5. Whenever you're ready (e.g. after reviewing/recording), click
   "Merge pull request." A squash merge is fine.

AFTER MERGING
-------------
Run these so the next demo starts from a clean, up-to-date main:

    git checkout main
    git pull
