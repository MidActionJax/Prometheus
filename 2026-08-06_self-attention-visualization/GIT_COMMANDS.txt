GIT / GITHUB COMMANDS — Self-Attention Visualization demo
=============================================================

Run these from E:\Linkedin in PowerShell or Git Bash:

    git checkout -b demo/self-attention-visualization
    git add .
    git commit -m "Add Self-Attention Visualization demo"
    git push -u origin demo/self-attention-visualization

WHAT HAPPENS NEXT
------------------
1. Pushing that branch will make GitHub show a "Compare & pull request"
   button on the repo page (or in the terminal output as a link).
2. Click it. For the PR title, paste:
       Add Self-Attention Visualization demo
3. For the PR description box, paste the full contents of
   PR_DESCRIPTION.md (in this same folder).
4. Click "Create pull request."
5. Whenever you're ready to publish, click "Merge pull request" — squash
   merge is fine.

AFTER MERGING
--------------
Run these so the next demo starts from the latest state:

    git checkout main
    git pull
