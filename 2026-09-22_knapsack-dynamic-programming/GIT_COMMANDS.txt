GIT / GITHUB COMMANDS — 0/1 Knapsack Dynamic Programming demo
================================================================

Run these from E:\Linkedin (the Prometheus repo root) using PowerShell
or Git Bash.

    git checkout -b demo/knapsack-dynamic-programming
    git add .
    git commit -m "Add 0/1 Knapsack Dynamic Programming demo"
    git push -u origin demo/knapsack-dynamic-programming

WHAT HAPPENS NEXT
1. After the push, GitHub will show a "Compare & pull request" button
   on the repo page (or in the terminal output as a direct link) —
   click it.
2. For the PR title, paste:
       Add 0/1 Knapsack Dynamic Programming demo
3. For the PR description box, paste the full contents of
   PR_DESCRIPTION.md (in this same folder).
4. Click "Create pull request".
5. Whenever you're ready to publish it, click "Merge pull request"
   (a squash merge is fine).

AFTER MERGING
Run these to get your local main branch back in sync before starting
the next demo:

    git checkout main
    git pull
