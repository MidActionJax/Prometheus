HOW TO RUN — Sorting Algorithms Race (Bubble vs. Insertion vs. Quicksort)
==========================================================================

1) INSTALL PYTHON (skip if you already have it)
   - Go to https://python.org and download the latest Python 3 installer.
   - During install, check the box "Add python.exe to PATH" — this is
     important, without it the commands below won't work.

2) INSTALL THE ONE DEPENDENCY
   This demo uses pygame. Open a terminal (PowerShell or Command Prompt on
   Windows) and run:

       pip install pygame

3) RUN THE DEMO
   In the terminal, navigate into this folder and run the script:

       cd path\to\2026-09-15_sorting-algorithms-race
       python sorting_algorithms_race.py

   A window should open showing three glowing columns of neon bars —
   labeled Bubble Sort, Insertion Sort, and Quicksort — all sorting the
   same shuffled array at once.

4) ON-SCREEN CONTROLS
   - R          reshuffle all three columns and restart the race now
   - SPACE      pause / resume
   - ESC        quit
   - closing the window also quits

   You don't need to touch anything — it runs and loops on its own,
   reshuffling and restarting a few seconds after all three columns
   finish sorting.

5) HOW TO SCREEN-RECORD IT
   Windows: press Win+G to open Xbox Game Bar, or press Win+Alt+R to start
   recording directly (press it again to stop). Alternatively, use OBS
   Studio (free, obsproject.com) for more control over quality.

   Suggested clip length: 10–20 seconds. A good moment to start recording
   is right after a fresh reshuffle — you'll capture all three columns
   racing from scratch, and with luck the Quicksort column finishing
   (and pulsing "SORTED") well before the other two.

6) POSTING
   Post the clip natively to LinkedIn (native video performs better than a
   link). Use the caption in caption.txt — copy it as-is or tweak lightly
   to fit whether you're posting to your own page or sharing in a group.
