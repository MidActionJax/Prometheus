HOW TO RUN THIS DEMO (Windows)
==============================

1. Install Python (skip if you already have it)
   - Go to https://www.python.org/downloads/
   - Download and run the installer
   - IMPORTANT: check the box "Add python.exe to PATH" before clicking Install

2. Install pygame
   - Open Command Prompt (search "cmd" in the Start menu)
   - Run:  pip install pygame

3. Run the demo
   - In Command Prompt, navigate to this folder, e.g.:
       cd E:\Linkedin\2026-09-17_electric-field-lines
   - Run:
       python electric_field_lines.py
   - A window titled "Electric Field Lines & Coulomb's Law" will open with
     three glowing charges already generating a field, and a stream of
     small gold particles flowing along it.

4. Controls while it's running
   - Left click: add a positive charge (magenta) at the cursor
   - Right click: add a negative charge (cyan) at the cursor
   - R: reset to the default charge arrangement
   - SPACE: pause / resume
   - Esc or close the window: quit

5. Record it for LinkedIn
   - Press Win + G to open Xbox Game Bar, click the record button (or Win + Alt + R
     to start/stop recording directly) while the demo window is focused.
   - Alternatively use a free tool like OBS Studio for more control.
   - Aim for 10-20 seconds. A good clip: let the default field settle for a
     couple seconds, then left-click to drop a new positive charge nearby
     and watch the field lines and particle stream reshape around it live.

6. Post
   - Upload the recorded video natively (not a link).
   - Use the caption in caption.txt in this same folder.

That's it — nothing else to configure.
